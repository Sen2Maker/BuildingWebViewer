# 相机动画

当前仅桌面网页的**网格模型查看器**启用。先加载 OBJ 三角网格，再点击顶部“相机动画”。

## 开启网页

```bash
cd BuildingWebViewer
python3 server.py --port 8892
```

打开 http://127.0.0.1:8892/lod.html 。停止服务按 Ctrl+C。新开终端再次运行同一命令即可重启；端口占用时换一个端口。

## 制作一段动画

1. 设置时长和 FPS，点击“应用”。例如 5 秒、30 FPS，共 150 帧。
2. 在第 1 帧调整视角并“打点”；定位到第 8 帧，改变视角后再打点。也可以先试“环绕示例”。
3. 每个关键帧可选择到下一关键帧的过渡：匀速、缓入缓出、加速、减速或保持后切换。◆ 可拖动；支持撤销重做。
4. 预览后展开“视频与帧序列导出”，选择格式、画幅和码率，开始导出。输出不含网页控件或声音。

第 1 帧对应 0 秒；第 N 帧对应 `(N-1)/FPS` 秒，最后一帧保留一个帧周期。例如 1 秒、8 FPS 输出恰好 8 帧。时长会对齐整数帧。时间轴可等比例调整关键帧或保留帧号，发生冲突会拒绝修改。

## 保存与导出

- 时间轴与输出设置自动保存在当前浏览器；JSON 用于备份和跨设备搬运，不包含模型文件。
- 动画绑定模型列表、顺序与排列尺度。加载另一组模型时请新建时间轴，避免误用视角。
- MP4 使用 H.264、WebM 使用 VP8；取决于浏览器编码支持。建议桌面 Chrome / Edge、通过 localhost 打开。不支持时改用 PNG 序列 ZIP。
- PNG 序列按选定 FPS 导入 PR / AE 等软件；ZIP 中附带动画 JSON 与帧率说明。
- 导出按指定帧数逐帧渲染，预览不流畅也不会跳过输出帧。可取消，结束后恢复导出前视角。
- 默认 720p，可选择横屏、竖屏、正方形或自定义偶数尺寸，总像素不超过 4K。预览会按输出画幅显示。
- 内存下载限制 128 MiB；浏览器支持时可勾选“直接写入文件”制作长视频。PNG ZIP 使用 ZIP32，直接写入也不能超过 4 GiB。
- 当前暂不支持音轨、视频剪辑、多轨合成、景深或贝塞尔路径；手机网页和 App 尚未接入。

## 开发说明

术语与复用边界见 [架构](ARCHITECTURE.md)。离线视频编码使用固定版本 Mediabunny，源码、完整性记录和许可证见 `docs/third-party/`、`assets/vendor/`。维护者可运行 `python3 scripts/vendor-video.py` 重建编码 bundle；日常启动无需安装依赖。

官方资料：[Mediabunny](https://mediabunny.dev/guide/writing-media-files)、[WebCodecs](https://developer.mozilla.org/en-US/docs/Web/API/WebCodecs_API/Using_the_WebCodecs_API)。
