# Gaussian viewer and editor

v1.4.0 高斯工具设计与边界。基于本项目界面实现基础高斯查看与修订，不代表 SuperSplat 全功能替代。

## 启动

在项目目录运行 `python3 -m http.server 8780 --bind 127.0.0.1`，打开 <http://127.0.0.1:8780/gaussian.html?lang=zh>。修改源码后执行 `python3 build.py`。

添加 Inria 风格的二进制小端高斯 PLY，可同时添加 `cameras.json`。勾选文件，在「数据 → 拍摄位置」选择训练机位。普通点云 PLY 应使用点云查看器。

## 第一人称漫游

点击渲染区上方「漫游模式」进入；「相机 → 第一人称漫游」调整转头灵敏度（默认 0.12°/px）和移动速度（默认每秒 0.15 个场景高度）。支持滑块和数字，本地保存。没有额外的惯性或平滑。

- 电脑：鼠标向右看右、向下看下；WASD / 方向键沿当前视线前后和左右移动，空格上升，Shift 下降。Ctrl 慢行至 20%；Esc 退出。
- 手机：左侧模拟摇杆移动，右侧拖动转头，右下方按住升降；可多指同时操作。小屏进入后铺满页面，退出按钮始终可见。电脑也可勾选「使用触屏摇杆」体验布局。
- 升降使用进入时相机的上方向，适配没有统一 Z-up 的重建场景。它是自由飞行，不带重力或碰撞检测，可以穿过模型。进入正交视图时切换为透视。
- 保留进入时镜头和机位，退出保留当前视角；切换工具、加载模型 / 机位、页面隐藏或失焦会退出，防止后台持续移动。
- 使用浏览器标准 [Pointer Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API)。内置浏览器或受限嵌入环境无法锁定鼠标时，提示按住画面拖动转头，键盘仍可移动。手机无需 Pointer Lock。

## 精细浏览

在「相机 → 环绕浏览手感」调整。旋转、平移和缩放分别支持 0.05–2 倍，默认 0.30 / 0.65 / 0.55。支持滑块和数字输入，一键恢复默认。

「随视距与视野自适应」让放大和窄视野下的旋转更慢；透视平移按观察目标所在平面的视距、FOV 和视口高度换算，正交模式按可见高度换算。这不是自动识别鼠标下模型表面距离。

「平滑移动」可关闭；时间范围 20–350 ms，默认 100 ms。数值是指数跟随的时间常数，越大越柔和但也越滞后；不额外模拟甩动惯性。按住 Ctrl / ⌘ 浏览拖动临时降到当前速度的 20%。框选 / 画刷模式仍使用 Ctrl / ⌘ 减选。

设置自动保存在当前浏览器的本地存储。平滑只用于交互导航，不用于拖延相机数字设置或训练机位跳转。页面隐藏、模式切换、加载机位会取消尚未完成的移动。触控走相同速度流程，仍需手机真机体验验证。

## 模块边界

- `src/gaussian/ply.js`：解析，保留源记录与未知属性。
- `src/shared/camera-geometry.js`：坐标约定、训练相机和共享投影函数。
- `renderer.js`：椭球投影、SH 着色、WebGL 资源及相机操作。
- `sort-worker.js`：后台排序，以 generation 拒绝过期结果。
- `edit-state.js`：选择 / 隐藏 / 删除状态、撤销事务、原始记录导出。
- `editor-controls.js`：编辑交互与高斯专用相机界面。
- `src/shared/camera-navigation.js` / `camera-navigation-controls.js`：输入速度、按时间平滑、自适应尺度和本地偏好。
- `src/shared/fly-camera.js` / `fly-controls.js`：第一人称位姿、键鼠与多指触控、生命周期及本地设置。
- `app.js`：导入、项目树和模块组装。

共享项目栏、布局、截图、运行状态继续使用 `src/shared/`。共享方向标尺在透视模式隐藏统一比例尺，避免错误的距离含义。

相机共享边界与接入规则见 [CAMERA-NAVIGATION.md](CAMERA-NAVIGATION.md)。

## 数据约定与限制

- 高斯中心、opacity、scale、rot、f_dc 必须为 float32；只接受二进制小端 vertex 数据。SH 高阶目前要求完整 45 项 f_rest；不支持压缩 PLY、SPZ、SOG 或大端/ASCII。
- 原始属性不经 sigmoid/log/四元数归一化反算后再导出；逐记录复制，保留自定义字段。一个导出对应一个源文件。
- 画刷与框选按当前预览中高斯中心穿透选择，可能同时选择前后两层；不是只选看得见的表面。全选针对勾选文件的完整数据。
- 尺度、透明度下限、显示抽样只改变预览；导出不烘焙这些显示参数。
- `cameras.json` 的 position/rotation 按 Inria camera-to-world 解释；支持完整旋转和 fx/fy。训练机位近裁剪默认 0.2 坐标单位，可在相机面板调整。手动浏览保留当前 roll 和垂直视野；立体 / 俯视 / 正视快捷视角恢复标准朝向。
- 适应窗口以中心 90% 的坐标估计构图，所有数据仍然参与渲染；不再自动缩小最大的 1% 高斯。
- 网页版高斯编辑状态在本次页面内存中，关闭前导出结果；Android 项目持久保存隐藏和删除标记。浏览器书签仅保存相机，不保存模型或编辑历史。
- 撤销历史最多占用 64 MiB，旧历史会淘汰；单笔事务超过预算会拒绝，避免不可撤销地修改。
- GPU 容量、浏览器内存仍有限；当前保留源字节和渲染数组，会占用多份内存。未验证 Android 真机和千万级场景。

## 本轮验证

- 新增状态、撤销预算、原记录导出、训练投影、无效旋转、反向排序、Worker 过期结果单元测试。

- 快速 PNG 与 1920 × 1080 重新渲染 PNG 均已实际下载并检查画面。构建检查及新增 7 项核心测试通过。
