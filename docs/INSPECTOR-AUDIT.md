# v1.1.0 设置面板核对

| 模块 | 已有能力与本轮调整 | 边界 |
| --- | --- | --- |
| 共用相机 | 滑块/数字、目标点、保持视角；快速 PNG、高级位图/SVG、纯净/辅助信息选择 | 快速截图不受高级导出视窗选择影响，保存所有可见渲染；SVG 不含辅助信息 |
| 共用书签 | 本地保存、加载、重命名、JSON 导入导出 | 当前只保存视角，不是完整项目备份 |
| LOD 显示 | 实体/线框、布局比例、编号、网格、面光照、边线材质、色带；增加图例独立开关与渐变终点颜色 | 不加入点云专属属性编辑；归一化布局标尺不可作为地理测量 |
| 线框显示 | 文件与叠加点云、同步对比、点大小/透明度/样式、比例；增加单色拾色器、图例/点数开关与终点颜色 | 每视窗当前是一份叠加点云；逐文件颜色管理只在多点云工具出现 |
| 点云显示 | 高度/RGB/HSV/标量/按文件着色、色带范围、点样式、比例滑块+数字；增加全局单色和逐文件覆盖/恢复 | 指定颜色只影响显示，不改属性/合并输出；颜色随本页项目条目保留，刷新不恢复完整项目 |
| 点云数据与处理 | 列标签/顺序、自定义语义、按选项计算、处理取消、合并及文件导出 | 不在本轮复制到不适用的 LOD 几何上；显示抽样不改变计算输入 |

原“每文件显示上限”改为“每文件读取上限”，与无需重读的显示比例区分。默认仍读取全部点。细线模式禁用无效线宽/渐变控件，单色选择器仅在全局单色时启用。每个工具仅显示其支持的渲染选项。

验证覆盖：回归套件；中文点云双文件与 ZIP、指定红/蓝、取消重选保色、缓存复用、比例数字与滑块；英文线框 ZIP 与立体线参数；中文 LOD ZIP 与共用设置；纯净/辅助截图实际像素差异；390px 无横向溢出。手机浏览器尺寸模拟不替代 Android 真机测试。
