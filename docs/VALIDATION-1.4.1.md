# v1.4.1 本地验证 / Local validation

发布基线：v1.4.1，nativeApi 保持 6，采用兼容网页热更新并复用 v1.4.0 安装包；模拟器专用调试 APK 不作为本次发布资产。以下记录发布前验证，公开部署状态以 GitHub Release 和 Actions 为准。

## 验证范围

- `python3 scripts/check.py`：36 个测试文件、95 项 Node 测试通过；包含五分钟调度、生命周期立即保存、无变化不写入、失败重试、完整快照复用、新导入数据快照提交。
- 高斯抽样读取限制单次读取不超过 1 MiB；覆盖全文件索引范围，不分配完整 SH 数组，预览禁止误导出成完整源数据；完整编辑标记、撤销历史跨预览切换保留。
- 后台排序缓存复用，连续方向与过期代次验证；平移不重排。
- `python3 mobile/prepare.py`：21 个 Android JS 文件通过 ES2017 语法检查、离线兼容检查；验证网页更新负载；发布时另行签名并由部署流程独立验签。
- Android 11 / WebView 83 专用模拟器，分别运行 `EditorWorkspaceTest`、`GaussianMobileTest`、`BackNavigationTest`，各 1 项通过。核验操作后 1.5 秒不写入、后台保存、重开不重写快照、返回先保存、五工具返回首页、10 万高斯默认 2 万泼溅预览、按需完整编辑、完整隐藏标记恢复以及手机关闭面板后继续框选。
- 初次原生测试暴露点云创作绕过共享调度器的问题，已修复。测试等待本地首页就绪后再切换页面，并以刷新标记确认新文档，避免旧 WebView 生命周期和旧 DOM 竞争；完整数据操作等待允许 15 秒，不能据此声称低配设备完整编辑流畅。
- 浏览器 390×844 中英文：轻量/完整切换、视距开启与关闭恢复、独立编辑标签、退出选区、无控制台错误。App 首页项目管理与维护默认折叠，作者/项目链接明确，旧 WebView 下额外补足链接间距。

## 可复现量级参考

桌面 Node、合成 10 万条带 45 个 SH 属性的球面数据：完整读取解析约 193 ms，轻量约 63 ms；解析结果保留的数组和原始字节分别约 47.2 MB 与 1.12 MB（不包括 GPU、原生桥接、文件缓存及临时读取缓冲）。仅为一次本地合成基准，不能推导用户手机 FPS 或真实场景性能。

## 已知边界

- 轻量泼溅按抽样间隔的平方根补偿屏幕覆盖，属于近似；细小结构与视角相关颜色会减少，不能保证所有输入完全保真。完整模式保留。
- 视距在顶点阶段提前拒绝远处高斯并淡出边界，减少后续着色和重叠绘制；不会减少原文件大小，也不会额外缩短本已受预览预算限制的排序数组。默认不裁切。
- 无可用 WebGL 2 的设备仍不能显示高斯。没有以模拟器或桌面测试代替实体手机性能验证。
- 系统强杀且未完成后台保存时，可能丢失最近五分钟的未保存操作；界面显示待自动保存，不将待保存误称为已保存。
- 已完成编辑保存；未完成绘制草稿仍须用户完成或取消再返回。
