# v1.2.2-preview.1 启动修复验证

2026-10-10。本地候选，尚未发布。继承 v1.2.1 兼容构建；本次重点是实际 Android 入口和独立诊断。

- 根因：Capacitor 8.5.3 直接拼接本地域名与 `appStartPath`，原路径缺少 `/`，得到 `https://localhostassets/mobile/index.html`。通用 `errorPath` 被错误标注为内核不支持；用户截图中的 WebView 151 并不能支持“内核过旧”的判断。
- 将入口修正为 `/assets/mobile/index.html`，构建校验及 Node 回归防止再次丢失前导斜杠或引入远程启动地址。45 项 Node 测试、生成资源与链接检查通过。
- 5 项原生单元测试通过，包括诊断地址脱敏、消息长度限制、格式和版本策略。APK 和仪器测试包编译成功。
- Android 11 / API 30 x86_64、WebView 83.0.4103.120 模拟器，飞行模式且默认网络为空：3 项仪器测试通过。真实 MainActivity 读取并显示项目首页、原生桥与报告入口；主动加载旧错误地址捕获 `-2 / net::ERR_NAME_NOT_RESOLVED` 并显示原生诊断；更新失败回退通过。
- 启动健康标记移到本地项目列表读取成功后；恢复正常后收起临时诊断浮钮。最终 APK 重测 3 项通过，截图检查首页及原生报告。无硬件加速模拟器不用于评价启动速度或手机性能。
- APK 内置资源与 Android 构建目录逐文件一致，实际打包入口含前导斜杠；签名与旧预览版一致，应用 ID 不变，versionCode 递增，可覆盖安装。
- Native API 3，保持预览应用 ID 与项目格式；报告最多记录每次启动 60 个事件并保留上次启动，支持手动复制/导出，不自动上传。
- 仍需用户手机验收：Android 15 / WebView 151、真实 QQ 分享、厂商 GPU、后台杀进程。模拟器和语法检查不代表所有 WebView 60+ 手机已通过测试。
