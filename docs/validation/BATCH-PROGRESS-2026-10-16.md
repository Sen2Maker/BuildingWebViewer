# 整批加载进度 · 2026-10-16

纳入 v1.8.2（2026-10-16），按用户指令发布。共享 batch-progress 模块用于线框、网格、点云与网页高斯；手机网页及 App 内的这些网页使用相同代码。

线框按选中的对象 ID 计数：每个对象的点云和线框任务均已结束后加一。同一 ID 的多个文件不重复算建筑。网格按模型，点云 / 网页高斯按选中文件计数，缓存命中也算完成。失败项计入已处理数量并明确标出失败数，不冒充成功加载。全部处理完后显示准备画面阶段。

百分比是对象完成数 / 总数，不按字节或耗时加权。一个大对象处理期间进度保持不动，读完才前进；不展示该对象的单独进度。未改变读取、缓存、渲染与点数策略。原生高斯本来就按整批数据扫描 / 打包进度展示，未改其原生加载路径。

138 项网页测试、生成包语法 / 资源链接检查、WebView 60 编译和 23 个脚本兼容检查通过。测试覆盖整批计数、失败统计、准备画面、进度不倒退、旧任务隔离和复用进度元素；网格结束时增加任务归属保护，避免旧任务隐藏新进度。

独立样式演示使用实际共享模块与页面 CSS，模拟 12 / 100 计数；390 × 844 下进度条宽 302px、页面无横向溢出。此为样式和计数验证，不是真实 100 栋建筑加载性能测试。截图在 .local-build/batch-progress-audit/mobile-preview.png。

## 确认后的正式外观

圆角平行四边形，浅蓝进度色块、深蓝百分比标签、淡蓝白斜条纹；标签数字反向抵消倾斜以保持端正。共享模块输出自定义外观，原生 progress 元素保留无障碍语义，装饰层不重复朗读。数量说明与百分比标签不重复显示。

直接运行正式共享模块的样式演示，在 390 × 844 下检查 0%、30%、100%，两端标签都在条形区域内，页面无横向溢出。原生高斯渲染界面不受此网页样式影响。新外观已完成完整网页回归和 WebView 60 编译检查，随 v1.8.2 发布。最终样例截图为 .local-build/batch-progress-audit/mobile-final-style.png。
