# 多文件文字溢出核查 · 2026-10-16

纳入 v1.8.2（2026-10-16），按用户指令发布。

线框多 ID 叠加将所有 `ID / 文件名` 通过 join 写入 geometry-note 和对比标题。说明区原来没有明确宽高限制，长名称会溢出或覆盖画布。高斯多文件标题也直接拼接全部名称。

修复采用共享 name-summary：默认最多展示两个名称，96 个 Unicode 字符以内，额外项目以 (+N) 标记；每个名称分配长度，避免第一个长名称遮住第二个 ID。悬停提示也有上限，完整列表保留在项目树。清空数据同步清理提示。

统一限制场景说明、工具标题和选中标签的边界。网格和点云原有标签栏保留固定最大高度与内部滚动，补充长名称省略和删除按钮不压缩；数据提示原有高度限制继续保留。点云创作没有拼接全部源文件标题的路径；Android 原生高斯的状态以数量摘要显示，没有同类全名拼接。

验证：136 项网页测试通过，生成包语法 / HTML 资源检查通过。使用真实线框页面 CSS 的独立压力页注入 2000 条超长 ID 文本，1280px 页面无横向溢出，说明区 56px、标题约 53px；390px 页面无横向溢出，说明区 15px、标题约 45px。此为布局压力检查，不代表加载 2000 份真实模型的性能测试。App 网页资源通过 WebView 60 兼容编译与 23 个脚本降级检查。未改原生 Java 或渲染算法；未做物理手机操作测试。
