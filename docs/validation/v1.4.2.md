# v1.4.2 diagnostic release validation

- Scope: rendering diagnostics only, based on v1.4.1. Experimental full-population rendering and fly descend changes are excluded.
- Node checks cover renderer classification, unavailable timing data, explicit sampling lifetime, and existing sort correctness with timing metadata.
- `scripts/check.py`, `scripts/release.py` and Android ES2017 compatibility preparation pass.
- Desktop browser: 100,000 synthetic Gaussians; GPU identity, source/submitted counts and separate GPU/CPU/worker timing samples present. Exported text parses as JSON and excludes dataset names/coordinates. A renderer identity is not a utilization measurement.
- 390 × 844 layout: readable scrollable report, reachable capture/copy/export controls.
- Android 11 / WebView 83 emulator: `RenderDiagnosticsTest` passes. It loads 1,000 synthetic splats, samples for ten seconds, confirms native metadata and timing fields, returns to project home and reads the persisted report.
- Native API stays 6. The release reuses the trusted v1.4.0 APK reference and ships a signed web update; a locally compiled test APK is not a release artifact.
- User's physical device has not been tested. GPU timer queries may be unavailable; missing values remain null. CPU command-submission time is not GPU time or FPS. Existing v1.4.1 performance/quality limitations remain.
