# v1.4.3 build repair validation

The v1.4.2 GitHub Release exists, but its Pages deployment was blocked by the signed-manifest/rebuilt-payload byte comparison. No v1.4.2 update manifest was advertised through Pages.

Root cause: esbuild followed a local node_modules symlink and embedded paths outside the release checkout in compatibility.js. A clean dependency installation in CI produced different bytes.

Fix: preserveSymlinks keeps the package paths relative to the checkout. A normal dependency directory and a symlinked directory now produce byte-identical complete .bwvupdate files. Signature and byte verification remain unchanged. All source checks, Android ES2017 compatibility preparation and package validation pass. Rendering diagnostics are unchanged from the tested v1.4.2 implementation. Native API 6 and the v1.4.0 APK reference are retained.
