# v1.4.4 release validation — 2026-10-11

Release validation record. Native API remains 6; the existing v1.4.0 APK receives the signed web update without reinstallation.

## Implemented

- Every preset retains all Gaussians. Old saved point caps are ignored. Quality presets, independent 0.5–2× pixel ratio, temporary motion pixel reduction and motion SH degree do not reparse or repack the model.
- Motion ends with a scheduled full-quality redraw. Export ignores temporary SH reduction. Full original data and editing flags remain available.
- Precompute static covariance once per upload; four-vertex triangle strips replace six unindexed vertices. Packed SH fetches reduce up to 45 scalar-fetch expressions to 12 vec4 fetches per vertex. Driver-level savings require measurement.
- Sort output reuses CPU upload storage and allocated GPU texture storage. Default Gaussian framebuffer is discardable; quick capture redraws and copies synchronously; advanced export retains its own FBO.
- Opt-in schema-2 diagnostics add CPU render time, CPU order upload time, on-demand draw intervals and consecutive motion draw intervals. None is presented as GPU completion time or presentation FPS.

## Passed locally

- `python3 scripts/check.py`: 38 test files, generated bundles and all HTML asset links.
- `node --test mobile/test-gaussian-quality-ui.mjs`: desktop/mobile defaults, English labels, retired cap and independent controls (DOM emulation, not browser layout).
- `python3 mobile/prepare.py`: all 21 Android scripts parse as ES2017; WebView 60 compatibility and offline project-home checks pass.
- `python3 scripts/release.py`: version, changelog, archive contents and checksum.
- Optional GLES regression (`scripts/validation/gaussian-gl.py`, system Python + Mesa): actual shader compilation and offscreen raster comparison against v1.4.3. 24 combinations of perspective/orthographic, SH 0–3 and scale 0.5/1/2; 900 anisotropic rotated splats including hidden/selected flags. Largest per-channel difference 1/255; largest mean channel difference 0.000340/255. Renderer: llvmpipe LLVM 20.1.2. This validates pixels, not mobile speed.

- Browser verification subsequently unblocked: actual WebGL image comparisons across 8 SH/projection combinations had maximum channel error 2/255, no channel exceeded 2. No WebGL errors. Motion quality changed to 0.65× / SH1 and restored to 1× / SH3 after settling.
- Actual viewer: import/select all 9,000 fixture splats, change quality without reducing count, change motion SH, export a nonblank 586×413 quick PNG; 390×844 settings layout checked. Advanced image FBO path exercised in all image comparisons.
- Full 594,870-splat synthetic model rendered without context loss. Single desktop RTX 3090 comparison at identical 392×567 pixels / SH3: GPU timer median 1.98 → 1.67 ms, P95 2.10 → 1.74 ms (62/63 samples). This is a short synthetic desktop sample, not a phone benchmark or an FPS promise. Earlier CPU `finish()` call durations are not used as performance evidence.

## Follow-up and validation limits
- Android/Adreno 730 comparison using the same 594,870-splat user dataset: continuous camera movement, frame interval and upload/CPU render diagnostics. The supplied phone does not expose GPU timer queries. No FPS gain is claimed from CPU submission timings or software-driver tests.
- Native Android test expectations were updated for full population and v1.4.4; emulator tests have not been rerun in this turn.
- Release metadata uses a fresh issuance time and 180-day expiry. Publication requires signing and byte verification of the rebuilt update payload.

The earlier full-population/chunked-rendering/fly-control experiments are preserved separately and are not silently included. This release does not claim to repair the native startup triggerEvent/404 warnings or the phone fly descend button.
