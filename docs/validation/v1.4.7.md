# v1.4.7 validation

- Source suite: 40 test files pass; generated bundles/HTML asset links and release version/archive/checksum checks pass. Android web prepare: 22 scripts parse as ES2017; offline home/missing API regressions and desktop/mobile quality UI pass.
- Actual WebGL2 desktop parity against v1.4.6: 12 perspective/orthographic, SH 0/1/3 and zoom combinations plus hidden/deleted/selected state, opacity cutoff, Gaussian scale and distance fading. Observed maximum per-channel difference 1/255; no visible-coverage loss in these synthetic cases. Direct vs optional projection reuse also differs by at most 1/255. A repeatable current-path parity fixture is in tests/browser/gaussian-projection.html.
- GPU timer experiments used RTX 3090: optional transform feedback at 594870 splats was slower (about 4.24 vs 1.96 ms in the initial experiment). It is OFF by default and lazily initialized. Further direct-path synthetic comparisons varied across opacity, SH degree and runs; no consistent all-device speedup is claimed. No Xiaomi/Adreno benchmark has been run locally.
- Default optimizations: fixed-width integer texture addressing; conditional SH bands; conservative complete-quad offscreen rejection; upload-time alpha support radius matching the pre-existing 1/255 fragment discard; R8 exact edit flags; removal of redundant fragment division. Source population and export attributes remain unchanged.
- Optional projection buffer: 44 bytes/splat, 26174280 bytes for 594870 splats (about 25 MiB), capped at 96 MiB. Failure falls back to full direct rendering. Disabling reuse, center preview or clearing the scene releases its allocation.
- Android 11/API 30 isolated emulator: RenderDiagnosticsTest passed, including default direct rendering, explicitly enabled projection reuse, no GL error, a 10-second automatic orbit sample and reading saved diagnostics after returning home. Native app unit tests and full same-version APK build pass. Unrelated third-party library instrumentation tasks were excluded after their own dependency conflict; project tests were not changed to hide failures.
- Diagnostics schema 4 distinguishes event timestamps-to-handler, requestAnimationFrame wait and manual/automatic sampling mode. Timestamps do not measure hardware touch latency; CPU submission is not GPU completion or presentation FPS. Auto orbit restores the saved pose and cancels on scene replacement.
- Native API remains 6. Full APK and signed web update are prepared locally; no publication until release authorization. Physical-device testing should compare the default path with the optional reuse switch in a stable continuous-drag/automatic sample.
